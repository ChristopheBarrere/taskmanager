# Task Manager

This is a simple task management application built with Django.

The goal of this project is to learn the basic concepts of Django by creating a CRUD application.

The application allows users to:

- View all tasks
- Create a new task
- Update a task
- Delete a task
- Mark a task as completed

## Technologies

- Python
- Django
- SQLite
- HTML
- CSS

## Project Structure

The project contains one main Django application called `tasks`.

The `tasks` application manages the creation, display, update and deletion of tasks.

## Task Model

Each task contains:

- A title
- A description
- A completed status
- A creation date
